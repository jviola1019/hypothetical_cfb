# GRIDIRON LAB v0.8 — Research integrity and playoff qualification

**Two-tab college football research simulator.** Choose Team A, Team B and venue in Game Simulation; explore source-backed school records, the separate experimental pregame evaluation, retrospective derived player-stat summaries where available, and coherent synthetic game distributions. Playoff Simulation includes 12-team CFP (2026–27), 24-team future CFP geometry (2027–28), and hypothetical formats.

**Evidence warning:** historical records, experimentally evaluated baseline predictions, and synthetic generated games are different things. Neither a sourced roster name nor a past-game hit fraction proves a player's current starting assignment or a future prop probability. The 2026 model check is *previously inspected*, not a pristine holdout. A new retrospective event-game conditional model has been added for audit only; calibrated unconditional player-prop probabilities remain unimplemented.

**Quick start:** `npm test && python3 -m unittest discover -s tests -p 'test_*.py' && npm run check && npm run build`; serve `dist/` with `python3 -m http.server` from the `dist/` directory. No npm runtime dependencies or paid API keys. GitHub Pages deploys automatically when Actions passes.

**Source data:** 2025/26 FBS team and roster snapshots, optional derived 2025/26 player-stat summaries, and a 2023–2026 pregame-model comparison, a 2024-residual score-interval evaluation, and a 2025-prior/2026 athlete-event evaluation generated by `.github/workflows/refresh-season-data.yml`. The refresh needs external downloads and can fail or lag. The player importer **does not redistribute raw individual game-event records**. Review CollegeFootballData terms, rights, provenance and limits in `docs/DATA_PROVENANCE.md` before further redistribution.

## v0.8 science / CFP update

A rules-as-data selector in `src/cfpSelection.js` can construct a **hypothetical** official-format 2026 or 2027 playoff field from verified externally supplied committee rankings and conference champions. It never invents actual committee rankings.

Two new empirical research pipelines are separate from the seeded fantasy game engine:

- `scripts/evaluate_score_distribution.py`: fixed 2024 score-residual distributions, 2025 and 2026 interval calibration / CRPS; artifact `public/data/score-evaluation-2026.json` appears only after a verified data refresh.
- `scripts/player_event_model.py` and `scripts/import_player_games.py`: Beta-Binomial exceedance conditioned on recorded event-game data, 2025 training priors and chronological 2026 evaluation. Source data do not identify all no-event appearances, so the results **are not full-game player prop odds**.

The CI includes automated consistency/security checks, plus an inlined Chromium DOM harness locally. Full browser Web Workers and iPhone Safari are not verified. See `docs/VALIDATION_V08.md` for limits, measured timings and release status.
