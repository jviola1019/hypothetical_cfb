# GRIDIRON LAB v0.7 — Quantitative audit release

**Two-tab college football research simulator.** Choose Team A, Team B and venue in Game Simulation; explore source-backed school records, the separate experimental pregame evaluation, retrospective derived player-stat summaries where available, and coherent synthetic game distributions. Playoff Simulation includes 12-team CFP (2026–27), 24-team future CFP geometry (2027–28), and hypothetical formats.

**Evidence warning:** historical records, experimentally evaluated baseline predictions, and synthetic generated games are different things. Neither a sourced roster name nor a past-game hit fraction proves a player's current starting assignment or a future prop probability. The 2026 model check is *previously inspected*, not a pristine holdout. Actual player-level predictive calibration remains unimplemented.

**Quick start:** `npm test && python3 -m unittest discover -s tests -p 'test_*.py' && npm run check && npm run build`; serve `dist/` with `python3 -m http.server` from the `dist/` directory. No npm runtime dependencies or paid API keys. GitHub Pages deploys automatically when Actions passes.

**Source data:** 2025/26 FBS team and roster snapshots, optional derived 2025/26 player-stat summaries, and a 2023–2026 pregame-model comparison generated by `.github/workflows/refresh-season-data.yml`. The refresh needs external downloads and can fail or lag. The player importer **does not redistribute raw individual game-event records**. Review CollegeFootballData terms, rights, provenance and limits in `docs/DATA_PROVENANCE.md` before further redistribution.
