# Data dictionary (client only)

`Team`: id canonical demo key; name display label; short display abbreviation. `TeamProfile`: synthetic offense, defense, tempo generated by id/year. `GameConfig`: teams, selected demo seasons, venue, pace, strength delta, 32-bit integer seed. `Drive`: offense/defense keys, own-yard-line start (0–100), net gain, aggregated plays, synthetic outcome, scored points, quarter, elapsed time, cumulative scores. `PlayerSlot`: QB/RB/WR1/WR2/TE/K aggregate stats, no individual identity. `Game`: two team aggregate boxes, drive list, final points, margin, total, winner, overtime count. `Tournament`: format, ordered seed participants, active slots, played fixtures, completed rounds, champion. `Sample`: N, counts and probabilities. No physical database exists; source lineage is in `DATA_PROVENANCE.md`. Historical validity metadata not yet implemented.
