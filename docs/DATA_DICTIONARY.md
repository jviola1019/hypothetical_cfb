# Data dictionary (client only)

`Team`: id canonical demo key; name display label; short display abbreviation. `TeamProfile`: synthetic offense/defense/tempo for most IDs; for four verified 2025 teams retrospective PPG-derived proxy with explicit coverage tag. `GameConfig`: teams, selected demo seasons, venue, pace, strength delta, 32-bit integer seed. `Drive`: offense/defense keys, own-yard-line start (0–100), net gain, aggregated plays, synthetic outcome, scored points, quarter, elapsed time, cumulative scores. `PlayerSlot`: QB/RB/WR1/WR2/TE/K aggregate simulated stats, associated with a verified 2025 athlete name only where a source exists. `Game`: two team aggregate boxes, drive list, final points, margin, total, winner, overtime count. `Tournament`: format, ordered seed participants, active slots, played fixtures, completed rounds, champion. `Sample`: N, counts and probabilities. `Observed2025`: historical full-season team record, points/game, selected athlete name and year-end totals. This data is **not pregame-safe**. `PropSummary`: simulated fixed threshold, athlete name if verified, sample count, mean, 10th/90th percentiles, above-threshold frequency. `HistoricalRosterImport`: optional CC0 roster, athlete ID, school and sanitized season stats. No physical database exists; source lineage is in `DATA_PROVENANCE.md`. Historical validity metadata not yet implemented.
