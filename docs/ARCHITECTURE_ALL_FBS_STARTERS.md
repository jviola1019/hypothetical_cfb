# 138-Team 2026 Personnel Audit — architecture and acceptance criteria

Baseline: 138 FBS school rosters, 15,187 roster-listed athletes, 828 simulated role slots. Only four assignments had dated source-backed roles before this upgrade.

The site models six source-linked offensive/special team roles per school: QB, RB, WR1, WR2, TE, K. This does NOT represent all 22 on-field starters. Player identities must be on their school's 2026 roster, position-valid, unique across slots, source-dated, and not ruled out this week. Recorded usage projections require same-year player stat-event samples.

Source hierarchy: dated game-day QB replacement reports, explicit depth-chart listings, third-party depth-chart projections, expired replacement identity only (maximum 21 days), season-to-date stat-event inference, roster-only fallback. Projections are never displayed as confirmed starts. Missing injury/availability data is UNKNOWN, not a clean bill of health.

Implement game-week correction evidence for Michigan, Tennessee, Houston and TCU, and sourced lower-confidence depth projections for selected other programs. Read-only, date-scoped snapshots are regenerated by the Friday/Monday workflow. Source URLs and date must be preserved.

CI acceptance: real 2026 data must show exactly 138 schools, 828 modeled roles, zero roster/position/duplicate/out/future-date mismatches, all 138 event-sourced selections backed by their own school's statistical summaries, plus existing JavaScript, Python and build checks. An independent verified depth chart for every school remains UNAVAILABLE; do not present 828 source-verified starters.
